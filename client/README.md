# Client unique : Next.js + API Express intégrée

Ce projet combine le frontend (Next.js) et le backend (Express) dans un seul dossier `client/`.

## 🚀 Lancement

### 1️⃣ API (backend)
```bash
node api/server.js
```
Accès : http://localhost:4000/api/teams

### 2️⃣ Frontend (Next.js)
```bash
npm run dev
```
Accès : http://localhost:3000

## ✨ Modules couverts
- Module 4 : React + Next.js
- Module 5 : Tailwind CSS
- Module 6 : Fetch & Rendu des données
- Module 7 : State & Formulaire
- Module 8 : Supabase (préparé)
